🔁 Циклдер (for, while)

Цикл дегеніміз бір әрекетті бірнеше рет орындауға арналған код құрылымы. Егер бір команданы немесе бірдей логиканы қайта-қайта жазу керек болса, онда цикл қолдану өте ыңғайлы. Бұл кодты қысқартады, түсінікті етеді және көп есептерді автоматты түрде шешуге көмектеседі.

Мысалы, сен 1-ден 10-ға дейінгі сандарды экранға шығарғың келсе, әр санды жеке-жеке жазудың орнына цикл қолданасың. Сол сияқты тізімдегі барлық элементтерді шығару, бірнеше рет есептеу жүргізу, шарт орындалғанша әрекет жасау сияқты жұмыстарда цикл өте пайдалы.

Python тілінде циклдердің негезігі екі түрі бар: for және while. Екеуінің мақсаты ұқсас болғанымен, қолданылу жағдайы әртүрлі.

📘 for циклі

for циклі белгілі бір элементтер жиынын қайталап шығу үшін қолданылады. Ол тізіммен, жолмен, range() функциясымен және басқа да iterable объектілермен жұмыс іштеді.

Егер қайталану саны алдын ала белгілі болса, көбіне for циклі қолданылады. Мысалы, 5 рет орындау керек болса немесе тізімдегі барлық сөздерді шығару керек болса, бұл өте қолайлы әдіс.

📗 while циклі

while циклі белгілі бір шарт ақиқат болып тұрғанша жұмыс іштеді. Яғни, шарт тексеріледі, егер шарт дұрыс болса, циклдің ішіндеги код орындалады. Шарт жалған болған кезде цикл тоқтайды.

Бұл цикл көбінесе қайталану саны нақты белгісіз болған жағдайда қолданылады. Мысалы, пайдаланушы дұрыс жауап бергенше сұрау, сан белгілі бір мәнге жеткенше есептеу немесе шарт өзгергенше әрекетті жалғастыру сияқты жағдайларда ыңғайлы.

while циклінің құрылымы

while шарт:
шарт ақиқат болғанша, ішіндегі код орындала береді.

Мысалы, n <= 5 шарты орындалып тұрғанша, программа 1, 2, 3, 4, 5 сандарын біртындеп шығара береді.

Маңызды: while циклінде шарт өзгеріп отыруы керек. Егер шарт ешқашан жалғанға айналмаса, цикл тоқтамайды. Мұндай цикл шексіз цикл деп аталады.

💡 Интерактивті орта

Бұл беттегі Python кодтары серверге жіберілмей-ақ, тікелей браузердің ішінде орындалады. Соның арқасында кодты өзгертіп, Run Code батырмасын басып, қателерді түзетіп, Python-ды компьютерге орнатпай-ақ тәжірибе жасай аласыз.

📊 Циклдер қай жерде қолданылады?

  • Сандарды ретімен шығару және тізімдегі барлық элементтерді қарау үшін
  • Бір әрекетті бірнеше рет қайталап, күрделі математикалық есептеулер жүргізу үшін
  • Пайдаланушы жүйеге дұрыс құпия сөзді енгізгенше ақпаратты қайталап сұрау үшін

⚠️ Жиі кездесетін қателер

1. Қос нүкте ұмытып кету

Python-да for және while жолының соңына міндетті түрде : қойылады. Болмаса, синтаксистік қате шығады.

2. Отступ (шегініс) қатесі

Циклдің ішіндегі код блогы міндетті түрде шегініспен (4 бос орын) жазылуы тиіс. Python шегініске өте сезімтал.

🧠 Тәжірибелік тапсырмалар

Бекемдеу үшін Sandbox-та мына есептерді шығарып көр:

  • for циклімен 1-ден 20-ға дейінгі тек жұп сандарды консольге шығар.
  • while циклін пайдаланып, 10-нан 1-ге дейін кері санайтын бағдарлама жаз.
